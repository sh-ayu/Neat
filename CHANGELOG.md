# Changelog

## [0.1.3] - 2026-11-27

First public release for Minecraft Bedrock 1.26.60.5 and LeviLamina Client 26.60.9 on Windows x64.

- Added overhead names, current and maximum HP, health bars that change color as HP drops, and optional armor values.
- Filtered armor stands, NPCs, and common decorative lobby entities. Labels respect block occlusion and HUD visibility.
- Added optional player labels based on the session roster. Unavailable HP is shown as `HP ?`.
- Added English and Japanese documentation. Vanilla mob names use the game's current language.

### 日本語

Windows x64 の Minecraft Bedrock 1.26.60.5 と LeviLamina Client 26.60.9 向けの初回公開版です。

- モブの頭上に名前・体力バー・現在／最大 HP・防具値を表示します。
- 防具立てや NPC を除外し、ブロックの遮蔽や HUD の非表示に対応します。
- 設定で他プレイヤーも表示できます。HP を取得できない場合は `HP ?` と表示します。
- モブ名はゲーム内の言語設定に従います。
